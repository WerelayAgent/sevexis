## Overview

Sevexis provides private, uncensored, open-weight LLM inference powered by decentralized compute on **Robinhood Chain**.

- **Network:** Robinhood Chain
- **Native Currency:** ETH
- **Settlement:** ETH / USDG
- **Launchpad:** Coming soon on [ponsfamily.com](https://ponsfamily.com/)
